# 与项目管理讨论并确认客户项目任务

选择一个真实文件夹即可开始，客户项目不需要 Legion 的 `.ans` 或开发团队。桌面主区是同一项目的项目管理会话，底部保留输入，左侧显示项目和动态成员，任务、上下文、来源详情按需展开，AI 连接在次级设置页。界面提供浅色、深色主题。首条需求创建或复用该项目的 PM；Human 只能给 PM 发消息或确认计划，执行成员只有状态与文件范围视图。

目录选择由主进程原生对话框完成。主进程验证真实目录身份，保存项目定义、会话和设置到应用 userData；讨论与选择不会在客户目录创建组织、角色、审计或其他文件。客户目录与 userData 相等或互为祖先时拒绝，真实链接别名也不能绕过。历史目录删除不会阻止选择新的有效项目；再次选择同一有效目录恢复其会话，切换时撤销旧执行并过滤迟到事件。

添加并选择默认 AI 连接后发送需求。讨论通过实际安装的 legion-runtime 0.4.0 公开 Pi Agent Service 多轮文本接口，工具和客户写入集合均为空；流式文本与本轮状态分别显示。停止回复只取消当前 PM 轮次，保留会话可继续。发送失败保留输入；成功仅清空已接受的那份输入，期间新编辑的文字保留。未选择项目或没有有效连接时显示可以操作的提示。

PM 方案文本是待校验数据。宿主校验角色、任务、依赖、连接及精确文件路径，绑定当前项目、组织版本、计划版本、连接版本和上下文后形成 digest。聊天正文不重复显示内部 `legion-plan` JSON 块，真实助手历史仍完整保存，可按需查看原始回复。结构化面板显示目标、动态角色、连接、任务依赖和逐个文件范围；格式无效时提示修复并继续讨论。模型声称批准不会产生许可。

Human 在详情中逐行填写明确的项目相对文件列表，最多 16 个文件、每个 256KiB、合计 2MiB。主进程通过品牌读授权验证根、路径组件、文件身份、大小和 SHA 后供本轮模型使用；不扫描目录、不启 SDK 默认读取。空列表清除上下文。上下文正文、注入的应用指令、密钥和许可不保存到会话历史，公开数据仅含文件路径、长度、摘要与验证时间。

点“确认当前计划”只发送当前项目 ID 和宿主 digest。Pipeline 重验完整绑定后，才建立各任务的品牌 authority，按依赖顺序运行动态执行成员；仅提供确认的 write_file 能力，实际文件提交经过 Policy 和 Mutation Service。任一根、上下文、连接或计划绑定失效均撤销同一计划全部旧 authority 与待运行任务；恢复旧 SHA 也不能重用确认。停止执行与关闭在入口先撤权，再等 SDK 和审计收束。另一项目的停止请求不能撤销当前项目权限。

结果显示实际成功写入数、缺失目标、拒绝、审计失败和任务状态。模型运行结束不等于文件生成；无工具写入或目标未全部生成时任务失败。软件检查显示“未运行（not_executed）”，当前版本没有任意 Shell 或自动测试执行能力。重启只恢复受限 user/assistant 文本及历史项目定义，旧 running 标为 interrupted，不恢复活动请求或确认许可。

AI 设置支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。连接含名称、协议、Provider 显示名称、模型 ID 和 Base URL；HTTPS 或明确 localhost HTTP 可用，URL 中认证信息、查询参数、fragment 拒绝。密钥保存明确选择保留、替换或清除；主进程 Electron safeStorage 负责加解密，无明文后备。公开数据只含 hasSavedKey。保存失败保留表单与新密钥，成功才清空新密钥。加密不可用、解密损坏、配置损坏等使用固定安全错误，不传 SDK 或密钥原文。

连接“测试”使用固定 Pi AI 1.0.4 三协议公开模块，normalizeContext 后 streamSimple(...).result()，tools=[]、maxTokens≤16、maxRetries=0、总截止时间和 stopReason 检查；运行中可取消。它证明该短请求的结果，模型费用和未知 metadata 保持 unknown。设置、映射或默认连接变更使旧绑定重新校验，不用显示文字替代授权。

每约一秒读取安全状态，手动刷新重新读取并验证 SHA。刷新不清空消息、设置密钥动作、PM 映射草稿、上下文草稿、状态筛选或滚动位置，也不重建正在聚焦的连接 select。新项目与页面导航回到页首，各项目消息草稿分别保存于当前窗口。执行成员点击会展开成员详情再定位，不能聊天或启动。

已有开发记录观察独立于客户动态团队，分别显示治理接受、task_ops 阶段与运行审计，均不声称进程在线。受控 YAML/角色边界、task_ops Markdown 完整机器链和人类表格、治理 snake reference-index 与 Core camel full-index 按实际版本验证。任务文件最多 16MiB、4096 事件、每轮读 64MiB；其他有限格式与小文件预算保持。缓存要求身份/mtime/size 未变，显示本轮观察与最近校验时间；手动刷新强制 SHA。缺失、损坏、未知格式、版本不匹配、链接、越界或超限明确不可用；保留旧有效快照时提示过期。来源失败不会把客户项目判成非法，也不会伪造 v004 治理事件。
